# InkFlow 纸页书房视觉基准

用户于 2026-11-02 选择最初三张效果图中的第一张。本项目按此图实现，后续生成的第三张修订图不作为实现目标。

参考图：`previews/workbench-paper-approved.png`。原图 1488×1056，实施时适配实际桌面窗口，不把整张图片用作应用界面。

## 布局

顶部为一条连续应用栏，左侧品牌与作品名，右侧专注、外观与平台窗口控制。左侧章节、中央正文、右侧资料都是与应用栏对齐的连续平面，使用细直线分隔。

左侧宽约 220，右侧约 280；中央占剩余空间，正文宽度最大 760，左右留白至少 48。资料可收起，专注模式收起两侧。窄窗口优先收起资料，避免挤压正文。

正文标题左对齐，文本使用中文衬线字体，界面控件使用清楚的系统中文字体。正文默认字号 20、行高 1.8、段间距 8、首行缩进两字。排版仅影响显示，原文保持纯文本。

## 颜色与层次

- 背景：暖灰纸张色 `#F3EFE7`。
- 编辑区：柔和米白 `#FFFDF8`。
- 正文：暖黑 `#302C27`。
- 强调色：低饱和棕 `#8B6245`。
- 分隔线：淡暖灰 `#E3DCD2`。
- 章节选中：浅棕底 `#E8D8C7`。

保留非常轻的纸张质感，不使用照片墙纸作为默认背景。章节列表是简单行，资料区不堆叠卡片；面板无悬浮阴影和大圆角。

## 可交互内容

章节新增、选择、重命名、重排与回收；正文编辑、撤销重做；大纲、角色、灵感切换；专注与资料收起；外观调整；返回书架；保存与字数状态。

原图中的小说为演示内容，不默认覆盖或替代用户作品。首次使用显示新建/打开入口；预览可以通过独立演示作品展示图中状态。

## 验证

以相同工作台状态对照参考图，检查布局、留白、字体、分隔、标题和状态栏。正常模式、资料展开、专注模式、外观面板、低亮度主题分别检查。Windows 与 macOS 的窗口控制遵循平台习惯，避免重复绘制原生按钮。

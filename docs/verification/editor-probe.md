# 正文编辑验证记录

日期：2026-11-02。平台：macOS 26.5 arm64；Flutter 3.41.9 / Dart 3.11.5；Xcode 26.6。

## 已验证

- `flutter build macos --debug -t lib/editor_probe_main.dart` 成功。
- 打开真实 macOS 窗口，正文按两字首行缩进和段间距显示；辅助功能读取到的正文没有添加缩进空格。
- 在原生编辑控件中将“旧书”替换为“新书”，再执行 Cmd+Z，实际窗口恢复“旧书”。
- 浅色与低亮度样式可显示，排版通过 NSTextView 的段落属性实现，读写接口保持纯文本。
- Dart 编辑状态测试覆盖排版变更不更改正文、选择、composing，以及原生事件传入的选择/组合范围。

Flutter 基础文本布局未提供每段首行缩进与段间距接口，因此正文区域采用系统纯文本编辑控件，主界面仍使用 Flutter。macOS 验证使用 NSTextView；Windows 原生适配尚未实现，当前 Flutter 回退文本框仅用于开发和测试，不代表 Windows 排版验收通过。

## 尚需验证

真实中文输入法候选过程、跨段编辑及撤销组合、10 万字章节与 300 万字作品性能、保存与输入并行、Windows 控件、系统缩放、退出与重新定位目录均未完成验收。

此验证程序不提供作品保存，不是正式写作版本。其入口与正式 main.dart 分离，后续工作台将使用已验证的编辑组件。

## 2026-11-03 更新

正式工作台现已接入该原生编辑控件和作品保存。Windows Rich Edit 适配已编写，但尚未在 Windows 上编译或验收，以上“尚未实现”是原型阶段的记录。

专注模式新增回归：切换时保持同一编辑器，进入和退出后可继续输入，正文及选择保持并能保存。此自动化检查运行于 Flutter 回退控件，不能替代 macOS/Windows 原生输入法验收。两端原生桥均补充主动获取焦点；macOS 编辑背景支持透明，以显示内置主题背景。

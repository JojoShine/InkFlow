# InkFlow 首版需求与设计

日期：2026-11-02  
状态：用户已于 2026-11-02 确认  
项目名称：暂用当前项目目录名 InkFlow

## 1 产品目标

为小说创作者提供一个愿意打开、能够安心长时间码字的桌面写作空间。核心体验是有氛围的私人书房：视觉温暖，操作顺手，资料随手可查，正文始终清晰。

参考妙笔、飞鱼等写作产品的使用场景，产品保持轻量。轻量同时体现在功能边界、界面干扰和运行体验上；主流平台的具体功能与视觉样式不直接构成本项目需求。

本文第 2 至第 7 节整理已确认的产品范围。第 8 节将其转化为实现约定，第 9 节给出验收方式，随本稿一并审阅；具体依赖、数据字段和开发任务留给实现计划。

## 2 平台与首版边界

- 使用 Flutter 构建 Windows 和 macOS 桌面应用。
- 本地优先，无需账号即可离线写作。
- 包含书籍与章节管理、纯文本编辑、自动保存、字数统计、TXT 导入导出。
- 包含层级大纲、轻量角色设定、灵感随记。
- 支持精选主题与适度自定义。
- 支持用户自选作品目录，配合已有网盘工具同步。

首版不包含 Linux、移动端、内置云同步、账号体系、AI 辅助、富文本、Markdown 格式编辑、人物关系图、时间线或伏笔管理。它们不作为首版设计和开发的前置条件。

## 3 启动与主工作台

### 3.1 打开后继续写作

启动后恢复上次作品、章节、光标位置和滚动位置。已有作品通过简洁书架切换；首次启动或没有可恢复作品时，提供新建作品、打开已有作品文件夹的入口。

作品目录暂时不可访问时，保留最近记录，提示重新定位目录，并允许打开其他作品。避免把暂时不可访问的作品当作空作品重新写入。

### 3.2 正文为中心的布局

- 左侧：作品章节目录，可以收起。
- 中间：正文编辑区，是主要视觉焦点。
- 右侧：大纲、角色、灵感的入口；按需打开，每次展示一类，可保持展开以便对照写作。
- 底部或其他低干扰位置：字数、保存状态等必要信息。

专注模式收起两侧面板，保留退出入口。退出后恢复原先的面板状态。书架与设置均为按需进入的辅助界面。

Windows 和 macOS 保持一致的产品结构，窗口操作、菜单和常用快捷键遵循所在平台习惯。

## 4 正文与创作资料

### 4.1 小说纯文本编辑

正文只保存文字与分段。字体、字号、行距、段间距、首行缩进和正文宽度属于显示设置，不向稿件写入格式标记。

支持章节新建、重命名、调整顺序、删除与恢复；编辑支持选择、复制粘贴、撤销和重做。章节顺序用于目录展示和整部作品导出。

中文输入法组合输入、候选词确认、光标移动、长章节滚动和撤销恢复是重点验证路径。自动保存、字数刷新和换肤不能重置正在进行的输入。

字数展示当前章节与整部作品的统计，具体计数口径在实现约定中统一。

### 4.2 轻度结构化资料

所有创作资料归属于一部作品。

| 类型 | 首版能力 |
| --- | --- |
| 大纲 | 标题、文本内容、父子层级及顺序 |
| 角色 | 姓名、可选简介、自由补充的文本设定 |
| 灵感 | 文本记录，可独立存在，也可关联一个章节 |

资料从右侧面板查阅和编辑。字段维持少量，不要求作者先完善设定才能开始正文创作。

## 5 主题与个性化

### 5.1 默认温暖书房

默认使用纸张色编辑区、暖灰界面和柔和层次。装饰适量，正文是视觉中心。精选主题统一控制界面底色、正文颜色、面板、选中状态和必要的边界颜色。

### 5.2 自定义范围

- 更换本地壁纸。
- 调整强调色。
- 调整编辑区透明度。
- 调整背景压暗和柔化程度。
- 即时预览，恢复当前主题默认值。

背景位于工作台底层，正文保留柔和底色。控件文字、输入光标、选择高亮和保存提示在各主题下都应可辨认。

应用主题与编辑排版分别保存。更换主题不覆盖字体、字号、行距和正文宽度，不改变光标、滚动位置、正文内容或面板状态。

### 5.3 动效与设备偏好

主题切换、面板开合使用克制的短过渡，提供关闭动效的选项。

主题、壁纸和排版偏好按设备保存，允许不同屏幕使用不同设置；作品内容随作品文件夹迁移和同步。

## 6 保存 同步与恢复

### 6.1 作品文件夹

每部作品对应一个文件夹，正文、章节顺序、大纲、角色和灵感一起保存。用户可以选择普通本地目录或自己的网盘同步目录。

应用负责本地读写和外部修改检测；文件的远程传输由用户的网盘工具完成。界面中的“已保存”表示已写入本地，不表示远程同步完成。

### 6.2 自动保存与失败处理

正文与创作资料自动保存，以低干扰方式显示状态。保存失败时明确提示，保留当前进程中尚未落盘的内容，允许重试或另存；失败状态不能显示为已保存。

应用退出前处理待保存内容。异常退出后的恢复以已经落盘的稿件、恢复记录和历史快照为依据，不承诺恢复尚未持久化的最后一次输入。

### 6.3 外部修改与同步冲突

检测到外部修改时，不用旧内存内容直接覆盖文件。发生冲突时保留双方版本，提供并排或切换比较，以及选用某版或另存双方的操作。

应用不自动合并正文。作品元数据发生冲突或损坏时，先保护原文件并提示恢复，避免用空目录、空章节或空资料覆盖已有内容。

网盘没有送达本机的修改无法被本机应用提前检测。首版面向顺序接续写作，不提供多人实时协作保证。

### 6.4 历史与回收站

本地历史快照独立于网盘同步目录保存。恢复历史前保留当前版本，允许撤回恢复操作。

章节、大纲、角色、灵感删除后先进入作品回收站，可恢复或明确永久删除。关联章节删除后，灵感内容继续保留，界面提示关联章节处于回收站；永久删除章节时解除关联。

## 7 导入 导出与迁移

- 导入 TXT：单个文件作为一个新章节导入，不覆盖现有章节。首版不自动识别并拆分长篇文件中的章节标题。
- 导出单章：导出当前章节的纯文本。
- 导出整部作品：按章节顺序合并，包含章节标题，以空行分隔。
- 完整备份：打包正文、顺序、大纲、角色、灵感与作品回收站；可恢复为一部独立作品，避免覆盖已有作品。

完整备份支持 Windows 与 macOS 之间迁移。设备上的主题偏好、外部网盘配置和独立本地历史快照不属于作品备份内容。

## 8 实现约定

以下为本稿提出的实现默认值，供本次审阅确认。

### 8.1 简单且可迁移的本地结构

作品使用稳定标识，章节文件以标识命名，显示标题和顺序放在带格式版本的作品清单中。每章保存为独立 UTF-8 TXT，创作资料按记录保存为独立结构化文件；标题修改不依赖章节文件重命名。

写入采用同目录临时文件替换单个目标文件；多个文件的操作通过操作记录恢复，不能把单文件替换视作整部作品的事务保证。保存前比较已读取版本，外部修改冲突另存保留副本。外部同步仍可能产生网盘自身的冲突副本，需保留并提示处理。

内置主题作为应用资源；用户壁纸复制到本机应用数据目录，避免原图移动后丢失。偏好、最近使用位置、恢复记录和历史快照保存在各系统的应用数据目录。

### 8.2 保存与历史默认值

- 输入停止 1 秒后触发保存；持续输入时至少每 10 秒尝试持久化一次。持久化过程不刷新编辑控制器或打断输入法组合状态。
- 离开章节、切换作品和正常退出时处理待保存内容。
- 正文与资料在内容变化后每 5 分钟生成历史快照，并在关闭、恢复或处理冲突前保留必要版本；相同内容不重复快照。
- 每条正文或资料记录保留最近 100 个快照，当前稿件与尚未处理的冲突副本不参与快照淘汰。
- 回收站内容由用户明确永久删除，首版不自动清空。
- 同一台电脑上，同一作品只允许一个编辑实例，第二个打开请求转到已有实例。

### 8.3 格式与统计默认值

TXT 导出使用 UTF-8；导入默认按 UTF-8 读取，失败时提供 GB18030 编码选择与预览，确认后导入，不静默替换无法识别的字符。

界面字数按 Unicode 字素簇计数，排除空格、换行和其他空白，标点计入；当前章节与全书使用同一规则，全书不计入标题、回收站与创作资料。统计可增量计算，避免每次按键重读整部作品。

首版提供“温暖书房”和同系的低亮度主题，均支持上述自定义。主题调整完成后自动按设备保存，恢复默认值只重置当前主题的自定义外观。

### 8.4 职责边界

- 工作台与主题：负责界面、布局状态、视觉配置和平台交互。
- 编辑会话：负责当前内容、输入与撤销状态、光标和保存调度。
- 作品与资料：负责章节顺序、大纲层级、角色、灵感与回收站规则。
- 本地存储与恢复：负责文件读写、版本比较、冲突保留、历史和备份。

界面通过这些边界访问数据，编辑逻辑与壁纸、颜色配置分离。首版不为远期云服务引入额外服务层。

## 9 首版验收

以下检查均须在 Windows 与 macOS 上完成；自动化覆盖数据规则和关键交互，真实桌面验证输入法、窗口行为和性能。

| 场景 | 通过标准 |
| --- | --- |
| 离线与启动 | 无账号、断网可新建和编辑；重启回到原作品、章节及有效光标位置 |
| 输入与撤销 | 中文组合输入、候选确认、粘贴和撤销重做正确；自动保存与换肤不丢输入、不跳光标 |
| 长篇编辑 | 使用 10 万字单章及 300 万字全书样本，检查输入、滚动、章节切换和字数更新；逐平台记录机器与测量结果 |
| 长篇性能判定 | 编辑响应无可感知的持续卡顿；在固定验收机器上，非输入法候选窗口操作的按键到可见文字延迟 p95 不超过 100 毫秒，章节切换不超过 1 秒；统计工作不阻塞输入 |
| 布局与资料 | 目录和资料可收起；专注模式可退出并恢复布局；资料编辑自动保存，删除关联章节不丢灵感 |
| 主题 | 两套主题可切换；壁纸、强调色、透明度及背景调节即时生效；恢复默认不改变正文与排版偏好 |
| 显示与动效 | 在 1280×800 与常用系统缩放下，主要操作可用；两平台的主题中正文、光标和提示清晰；关闭动效后功能完整 |
| 保存失败 | 模拟目录失效、无写权限和空间不足，显示失败并保留会话内容，可重试或另存，不显示虚假成功 |
| 同步冲突 | 模拟外部修改与网盘冲突副本，双方内容可找回；冲突未处理时不静默覆盖已检测到的外部版本 |
| 异常恢复 | 在保存和多文件操作中途结束进程，重新打开后已有有效稿件可读，未完成操作可恢复，异常文件不被空内容替换 |
| 历史与回收站 | 可恢复正文及资料；恢复前保留当前版；删除内容可找回；快照保留规则符合约定 |
| 导入导出 | UTF-8 与 GB18030 样本导入正确；导出章节内容及顺序正确；整书导出不含回收站内容 |
| 完整迁移 | 备份在另一系统恢复为独立作品，正文、资料、关联、章节顺序和回收站一致 |

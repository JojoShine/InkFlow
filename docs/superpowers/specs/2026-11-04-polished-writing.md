# 排版整理与片段分享

用户已确认按建议实施本轮两个功能：一键排版整理、片段分享卡片。全书查找替换、DOCX/PDF 导出、每日目标留待后续。

- 编辑区底部提供“排版／分享”快捷入口，紧邻码字统计；作品菜单不重复收录。沿用原宋体与现有主题/图标。弹窗可滚动、标签外置；应用/导出过程中阻止重复操作。
- 排版整理作用于选中部分或当前章节。清理段首缩进空格、段尾空白，合并过多空行；规则可开关，默认保留一个空行和场景分隔文字，不替换标点/原句。展示整理前后与变更数量，确认前不改正文。处理 UTF-16 选区边界、CRLF、空文本、中文和 emoji。
- 应用前提交输入法并核对章节/正文快照，发生切换或修改则拒绝过期预览；保留历史快照。macOS/Windows 原生编辑器以单次可撤销编辑替换文本，普通平台提供同等撤销。整理不计入码字速度。
- 分享默认采用当前选区，无选区则采用首个非空段落；内容可在卡片窗口调整，稿件不变。花影纸笺／星夜手记／像素漫游／胶片手记四种样式，装饰保留在页角和底部，作品名、章节名、可选署名。可预览，保存 PNG 和复制片段文字；不自动发送到外部服务。
- 分享正文上限 600 个可见字符，超限明确提示，不静默截断。渲染保留分段/emoji，完整绘制正文，图片宽 1080px、高度按文字自适应。选择保存位置，取消不写文件；禁止导出到作品记录目录内。
- 验证仅使用临时作品/样例，原有用户稿件不应用排版、不导出。检查现有保存/编辑/主题/AX 回归；macOS 原生撤销可单独探测，Windows 若无运行环境明确记录限制。

- 正文编辑区使用右边缘细滚动条，滚动或悬停时出现并可拖动；到底部显示返回顶部。滚动定位不改变正文、选区与输入法状态。
